# 钢铁前线

原创即时战略游戏（单文件 HTML + three.js）。四个国家、人机对战、最多 4 人联机混战。

- 四国各不相同：北岭（钢铁洪流）、赤砂（机动游击）、金穗（经济与阵地）、灰鹰（精锐与空中）各有一整套步兵、坦克、飞机、舰船和防御塔，建筑数值也不同；特色能力有喷火、伪装、伏击、部署、电子干扰、两栖、伪装网
- 四国地域建筑风格：北岭石砌陡坡顶和红砖烟囱、赤砂土坯平顶圆顶和捕风塔、金穗白墙红柱青瓦飞檐、灰鹰拱形金属机库和雷达罩天线塔，每国一整套建筑外观
- 建筑动画：脚手架和塔吊下分段组装、墙体一层层砌高；出售时倒放拆解；被毁时逐件坍塌并留下永久废墟（可在上面重建）；生命低于 50% / 25% 会熏黑、破洞、塌角；战车从卷帘门开出、步兵从门口走出、直升机从停机坪升空；传送带、旗子、信标、维修吊钩等工作动画

- 每种单位都有专属模型，四国 69 种单位外观各不相同
- 村庄争夺：每个小镇有一座村公所，由老兵民兵、反坦克组、武装皮卡和轻型坦克把守；消灭守军后派工程师占领，首次攻下奖励 $1500，之后每秒 $6；无人占领 120 秒后守军刷回
- 村庄是前线据点：占领村公所后，周围 6 格内可以建造；每个小镇旁还有一座采矿场，守军清完后派工程师占领，每秒 $5，不需要矿区
- 民房为欧式乡村风格，4 种房型（平房、两层小楼、L 形农舍、带棚屋）× 随机配色，同一个小镇里每栋都不一样
- 平衡调整：四国各自胜率约 40%～60%（电脑对战测试）
- 操作：WASD / 方向键移动视野，Q 攻击移动，X 停止

- 老兵制度：单位击杀敌人积累经验，晋升老兵、精英
- 三种地图：大陆 / 内海（海战）/ 三国鼎立（3 方专用圆形战场，三家 120° 对称，中央岩墙要塞里有村庄和宝石矿）
- 海军：船厂、巡逻艇、驱逐舰、潜艇（隐身）、导弹巡洋舰
- 空军：直升机 + 机场固定翼飞机（截击机、攻击机、轰炸机，弹药打完回机场补给）
- 天气与昼夜：一天 20 分钟，只改变画面氛围，不影响视野
- 总部制：总部被攻陷即战败，战略导弹对总部无效
- 反导系统：自动拦截保护范围内的敌方战略导弹，拦截后需要装填
- 步兵加强：步兵碉堡可进驻 5 人；兵营研究防弹衣、穿甲弹、战地急救；步兵只受 60% 溅射伤害
- 人口上限与副部：建筑提供人口（上限 150），副部可在远处开设前进基地
- 地形：平地战场，河流与可炸断的桥、浅滩、小镇民房进驻、公路/林地/沙地影响速度，林地步兵可隐蔽
- 军事研究所：研究复合装甲、火控、自动化精炼、热成像、主动防护、野战维修、精确制导、电子对抗 8 项永久升级
- 小号地图 + 快速节奏（默认），1v1 约 30 分钟一局
